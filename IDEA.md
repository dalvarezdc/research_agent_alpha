This project is a UX/UI to do medical research and medical reports. It should be separated by patients. And we should be able to input medical data, save it in databases, classify it, organize it, show it in a timeline for the patients, so the patients understand their current status. For example, if an illness was cured, we have to know if you have a chronic condition, you have to know the status. You have to be able to track the measurements of sugar or all of everything you have.
